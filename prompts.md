# prompts.md — пошаговые промпты для Antigravity (Gemini Flash)

Как работать: запускай промпты ПО ОДНОМУ, после каждого смотри результат (PNG в папке export/). Не переходи дальше, пока текущий шаг не принят. Если агент «улучшает» палитру или шрифты, остановите его и верни к tokens.css.

## Структура проекта (положи файлы так)
```
project/
├── brief.md                  (формулировки трёх заданий)
├── lecture.md                (текст лекции 5)
├── content.kk.md             (готов)
├── glossary.kk.md            (готов)
├── design-system.md          (из кита)
├── prompts.md                (этот файл)
├── export.py
├── css/  fonts.css  tokens.css  base.css
├── fonts/files/              (woff2)
└── .agent/skills/ ...        (скиллы)
```

## ШАГ 0. Знакомство (без кода)
```

Кода пока не пиши. Ответь списком, коротко:
1) какие три изделия нужно сделать и в каком формате (A4 landscape, тройной сгиб, 6 панелей; постер A4 portrait);
2) какие скиллы ты будешь применять на каких шагах;
3) что в content.kk.md помечено [ТЕКСЕРУ] (не менять, просто перечисли);
4) есть ли в твоём плане что-то, что противоречит design-system.md.
Важно: дизайн-система УЖЕ задана (цвета, шрифты, концепция). Скилл ui-ux-pro-max не должен генерировать новую систему или менять палитру. Используй его только для идей по композиции и деталям.
```

## ШАГ 6. Полировка и сдача
```
Скилл impeccable (режим критики и полировки), затем render-qa-loop.
1) Открой все 5 PNG из export/ и дай критику по каждому: иерархия, воздух, выравнивание, единство серии. Список конкретных правок, без переписывания файлов целиком.
2) Внеси правки точечно (str_replace), потом заново запусти export.py.
3) Проверь по brief.md: все три задания выполнены, заголовки официальные, слоганы на месте, терминология из glossary.kk.md, нет текста вне content.kk.md.
4) Создай design-notes.md (до 1 страницы, по-русски): идея «санақ жүйесі + бір есеп көп шешім», как дизайн связан с темой, какие принципы доступности применены (контраст, форма маркера кроме цвета, кегль, иерархия), какие шрифты и почему.
5) Выведи итоговый отчёт: что проверено, что осталось на решение пользователя, список мест [ТЕКСЕРУ] для проверки носителем.
```

## Если что-то пошло не так
- Текст не влезает: сократи в content.kk.md, а не уменьшай кегль ниже токенов.
- Агент сменил шрифт или цвет: «Верни значения из tokens.css, верни шрифты Onest/Golos Text».
- Казахские буквы отображаются другим шрифтом: проверь, что подключён css/fonts.css и файлы лежат в fonts/files/.
- PDF с лишней страницей: значит, контент вылез за 297×210 мм; найди блок через export.py (он пишет предупреждение о переполнении).
